# 換圖說明

把圖片用**指定的檔名**放進這個資料夾（`assets/skin/`），遊戲就會用你的圖取代原版。
不用改任何程式碼。

> 每個檔名對應到什麼，請看同資料夾的 **`_對照圖.png`**。

---

## 三個步驟

1. 準備圖片（AI 生成、免費素材網站或自己畫都可以，見下方「圖片從哪裡來」）
2. 把檔名改成下表的名稱，放進 `assets/skin/`
3. 看結果（見下方「怎麼看到結果」）

沒放的部位會自動使用原版圖，所以**可以一次只換一個**。

---

## 檔名規則

- **只有一張圖的**：`名稱.png`，例如 `bg-sky.png`
- **有動畫的**：`名稱-1.png`、`名稱-2.png`……，例如 `player-run-1.png`、`player-run-2.png`
  - 動畫**只給第 1 張也可以**，整個動作就都用這張；也可以直接存成 `player-run.png`
  - 只要放了任何一張，這個動作就**全部改用你的圖**，不會跟原版混在一起
- 格式：`png`、`jpg`、`webp` 都可以
- 大小寫、空白、底線都沒關係：`Player_Run 1.PNG` 也會被認得
- 檔名開頭是 `_` 的檔案（像這份說明）會被忽略

檔名打錯的話，遊戲開始畫面會出現**黃色提示**告訴你是哪個檔案。

「遊戲中大小」只是參考，**圖片不用剛好這個尺寸**，形狀比例接近就好，遊戲會自動縮放。

- 圖片大小**沒有上限**，但超過 2000 像素寬的圖會讓開始畫面載入比較慢
- 角色、怪物、文字會**等比例縮放**，比例不同也不會變形
- 背景會**拉伸填滿**，比例差太多會被壓扁或拉長；
  建議寬高比：天空約 5:2、遠山約 3:1、中山約 4:1、近山約 14:1、地面約 7:1

## 遊戲會自動幫你做的事

- **自動去背**：角色、怪物、文字如果是**純色背景**（例如白底），會自動變透明
- **自動裁掉空白**：圖片四周多餘的空白會被裁掉，角色不會變得很小
- **自動縮放**：等比例縮到遊戲裡的大小，角色和怪物會站在地上
- **碰撞範圍跟著圖走**：圖上有畫到的地方就是碰撞範圍，不用另外畫
- **背景自動接縫**：背景會一張正、一張左右翻轉接下去，所以左右邊緣不用對齊
- **山的天空自動透明**：山的圖如果上方是純色天空，天空會自動變透明，後面的背景才看得到

## 圖片從哪裡來

### 方法一：免費素材網站（不需要任何訂閱）

| 網站 | 說明 |
|---|---|
| [Kenney](https://kenney.nl/assets) | 大量 2D 遊戲素材，**CC0 授權**，可自由使用、不用標示作者，最推薦 |
| [OpenGameArt](https://opengameart.org) | 遊戲素材社群，授權每個作品不同，下載前看清楚 |
| [itch.io 免費素材](https://itch.io/game-assets/free) | 很多像素風角色和背景，授權每個作品不同 |
| [Pixabay](https://pixabay.com) | 插畫、向量圖，可免費使用 |

**授權要注意：**

- 這個遊戲會發布到 GitHub Pages，**任何人都看得到**，所以要用「允許公開使用」的圖
- **CC0**：隨便用，最省事
- **CC-BY**：可以用，但要在 README 寫上作者名稱和出處
- **不要直接用 Google 圖片搜尋到的圖**，大部分有著作權

### 方法二：免費的 AI 生圖

不用付費訂閱也有免費額度可以用（各家方案常變動，以官網為準）：

- **Microsoft Copilot／Bing Image Creator**：用 Microsoft 帳號登入即可
- **Google Gemini**：用 Google 帳號登入即可
- **ChatGPT 免費版**：每天有少量生圖次數

### 方法三：自己畫

- [Piskel](https://www.piskelapp.com)：免費的線上像素畫工具，可以直接畫動畫、匯出 png
- 在白紙上畫，用手機拍照：光線要平均、背景要乾淨，遊戲才能自動去背

### 去背工具（如果自動去背不夠乾淨）

- [remove.bg](https://www.remove.bg)：上傳照片自動去背
- [Photopea](https://www.photopea.com)：免費的線上修圖工具，用法類似 Photoshop

## 給 AI 的提示詞

把 `{情境}` 換成你想要的主題（例如「海底世界」、「森林」、「城市」）。
**先生成主角**，滿意之後，把主角圖一起給 AI 當「風格參考」，再生成其他東西，畫風才會一致。

**角色和怪物通用：**

```
{情境}主題的 2D 像素風遊戲角色：{描述}。
全身、置中、純白色背景，不要文字、不要陰影、不要邊框。
```

| 檔名 | `{描述}` 可以這樣寫 |
|---|---|
| `player-run` | 主角正在跑步，側面朝右 |
| `player-duck` | 主角蹲低縮成一團，側面朝右 |
| `player-jump` | 主角跳在空中，手腳張開，側面朝右 |
| `player-dead` | 主角被撞倒躺在地上，頭上冒星星 |
| `ground-slime` 等地面怪 | 矮矮的、在地上爬的小怪物，面朝左 |
| `air-saucer` | 浮在空中的東西（飛碟、氣球、鳥都可以），面朝左 |
| `air-dragon` | 會飛的大怪物，翅膀張開，面朝左 |

**背景：**

```
{情境}主題的 2D 像素風橫向捲軸遊戲背景：{描述}。
寬度大約是高度的 3 倍，不要人物、不要文字。
```

| 檔名 | `{描述}` 可以這樣寫 |
|---|---|
| `bg-sky` | 遠方的天空，沒有地面 |
| `bg-mountain-far` | 遠處的山（或珊瑚礁、大樓）剪影，上半部是純白色天空 |
| `bg-mountain-mid` | 中距離的山丘剪影，上半部是純白色天空 |
| `bg-mountain-near` | 很扁的近處小山丘，上半部是純白色天空 |
| `bg-ground` | 地面的橫切面，例如沙地、草地、石頭路 |

**文字：**

```
遊戲標題文字「{你的文字}」，像素風格字體，純白色背景，只有文字。
```

AI 寫中文字常常會寫錯，文字類的圖可以改用 [Canva](https://www.canva.com) 或簡報軟體自己做，存成透明背景的 png。

## 怎麼看到結果

**方法一：在自己電腦上看**

1. 在專案資料夾開啟終端機，執行 `npm run watch`
2. 用瀏覽器開啟 http://localhost:3000
3. 之後每次放新圖，**按 F5 重新整理**就看得到

**方法二：完全不用終端機**

1. 開啟 GitHub 上的專案頁面，進到 `assets/skin` 資料夾
2. 按 **Add file → Upload files**，把圖片拖進去，按 **Commit changes**
3. 等 1～2 分鐘，GitHub 會自動更新網站

**方法三：拿到的是編譯好的資料夾（壓縮檔）**

如果你拿到的是解壓縮後有 `index.html`、`bundle.js` 的資料夾，不需要 npm，也不用重新編譯：

1. 把圖片放進這個資料夾裡的 `assets/skin/`（就是這份說明所在的資料夾）
2. **不能直接雙擊 `index.html`**，瀏覽器會擋住讀圖和麥克風，要用本機伺服器開啟，二選一：
   - **VS Code**：安裝「Live Server」擴充套件，在 `index.html` 上按右鍵 →「Open with Live Server」
   - **Python**：在資料夾開啟終端機，執行 `python -m http.server 8000`，再用瀏覽器開啟 http://localhost:8000
3. 之後每次放新圖，**按 F5 重新整理**就看得到

這個方法要靠本機伺服器列出資料夾裡的檔案。如果是把編譯好的資料夾上傳到網站（例如 GitHub Pages），
網站不會列出檔案，新放的圖就不會生效；這時請改用方法二，把圖放進原始專案的 `assets/skin/`。

## 想還原成原版

把 `assets/skin/` 裡你放的圖片刪掉就好（這份說明和對照圖不用刪）。
原版圖片都在 `assets/skin-original/`，**請不要修改那個資料夾**。

## 常見問題

**開始畫面出現黃色文字？**
那是檔名有問題的提示，照著提示改檔名就好。

**放了圖卻沒有變，也沒有黃色文字？**
- 確認網址是 `http://localhost…` 或 `http://127.0.0.1…`，不是 `file:///…`（不能直接雙擊 `index.html`）
- 確認圖片放在**你開啟的那個 `index.html` 旁邊**的 `assets/skin/` 裡
- 在原始專案裡放圖的話，要開著 `npm run watch`，或重新執行 `npm run build`
- 按 **Ctrl + F5** 強制重新整理

**角色周圍有一圈白邊？**
自動去背只能處理很乾淨的純色背景。可以請 AI 生成「透明背景 png」，或用上面的去背工具處理。

**撞到怪物的時機怪怪的？**
碰撞範圍就是圖上不透明的地方。如果怪物旁邊有沒去乾淨的背景，也會被當成怪物的一部分。

**換了山的圖之後，後面的背景整片被蓋住？**
山的圖要讓天空透明：上半部用純色（例如純白），或直接用透明背景的 png。

**網頁分頁上的標題文字怎麼改？**
改 `html/index.html` 第 6 行 `<title>` 裡的文字。
